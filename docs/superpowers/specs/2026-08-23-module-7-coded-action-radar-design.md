# 模块 7 代码化行动雷达设计

## 目标

将模块 7 的展示改为“股票候选代码池 → 股票/基金替代表达 → ETF 候选代码池”的三栏联动工作台。页面必须显示明确股票和 ETF 代码，并只在执行资格成立时生成一个互斥的行动动作。

## 已确认范围

- 展示 7C 的十只股票候选与 7D 的十只 ETF 候选，代码和名称固定为候选池身份。
- 展示 7E 的代码对代码替代关系。
- 研究状态只允许：`深挖`、`验证中`、`候补`、`数据不足`。
- 执行动作只允许：`重仓`、`中仓`、`分批浅仓`、`暂不追高`、`退出观望`。
- 不展示仓位金额、目标百分比或用户资产金额。
- 现有 `fundHoldings` 是基金观察池，不与 7D ETF 候选池混为一个排名。

## 数据边界

7C、7D、7E 的 Notion 原表提供了代码和关系，但其 2026-08-14 的分数、价格、排名、触发价与“今日方向”是演示/代理数据。实现仅可继承代码、名称、主题和关系；不得将上述旧值写入当日快照或作为今日行动结论。

当日数据缺少股票或 ETF 的有效行情、研究覆盖或执行模型时：

- `executionEligible` 为 `false`；
- `executionAction` 为 `null`，而非从五类动作中猜选一个；
- 页面显示固定系统状态“执行引擎未启用”，并展示不可执行原因；
- 不得用“暂不追高”替代“数据不足/模型未启用”。

## 数据合同

新增 `codedOpportunityRadar`，并保留既有 `opportunityRadar` 以避免破坏当前模块 7 页面。

```ts
type ResearchStatus = "深挖" | "验证中" | "候补" | "数据不足";
type ExecutionAction = "重仓" | "中仓" | "分批浅仓" | "暂不追高" | "退出观望";
type ExpressionStrategy = "股票优先" | "基金替代" | "并行持有" | "双双观望";

type CodedCandidate = {
  code: string;
  name: string;
  assetType: "股票" | "ETF";
  theme: string;
  researchStatus: ResearchStatus;
  executionEligible: boolean;
  executionAction: ExecutionAction | null;
  actionRationale: string;
  nextTrigger: string;
  invalidCondition: string;
  dataDate: string | null;
  dataStatus: string;
};

type CodedRelationship = {
  stockCodes: string[];
  etfCode: string;
  relationship: string;
  expressionStrategy: ExpressionStrategy | null;
  relationshipStatus: "已验证" | "关系待验证";
};
```

## 判定约束

1. 每个候选必须恰有一个 `researchStatus`。
2. `executionEligible=false` 时 `executionAction` 必须为 `null`。
3. `executionEligible=true` 时 `executionAction` 必须是五类动作之一。
4. 候选代码不在固定候选池内时，构建失败，不渲染该候选。
5. 7E 的每个股票代码和 ETF 代码必须分别存在于 7C、7D 候选池。
6. 候选代码、数据日期与当前快照业务日期必须分开显示。
7. 没有有效执行模型时，界面顶部显示“执行引擎未启用”，单卡不得伪造动作标签。

## 界面结构

桌面端：顶部系统条；左侧 7C 股票候选；中间 7E 替代表达；右侧 7D ETF 候选；底部选中项证据板。

每张候选卡固定顺序：代码与名称、主题、研究状态、执行行动或未启用原因、行动依据、下一触发、失效条件、数据日期。

三栏选中状态联动：选择股票时高亮所有关联 ETF；选择 ETF 时高亮关联股票；中间栏展示该组关系及表达策略。移动端按股票、替代关系、ETF、证据板的顺序纵向折叠。

## 验收标准

- 7C 必须显示十个明确股票代码，7D 必须显示十个明确 ETF 代码。
- 7E 不得出现仅以主题名称关联、但无代码关联的记录。
- 数据不足或执行模型未启用时，不得出现五类行动动作。
- 有资格的候选只可出现一个行动动作。
- 旧演示日期、分数、价格与旧“今日方向”不得进入日更产物。
- 生产构建通过；静态 HTML 含 7C、7D、7E、代码候选和“执行引擎未启用”状态。
